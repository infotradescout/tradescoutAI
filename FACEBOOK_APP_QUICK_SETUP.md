## Quick Facebook App Setup Steps

1. **Go to** https://developers.facebook.com/
2. **Create App** → Choose "Consumer" 
3. **App Name**: "TradeScout"
4. **Add Facebook Login** → Web platform
5. **Configure OAuth Redirect**: Use URL above
6. **Add Privacy Policy**: Use URL above  
7. **Add Terms**: Use URL above
8. **Get Credentials**: Copy App ID and App Secret
9. **Add to Replit Secrets**:
   - `FACEBOOK_APP_ID`
   - `FACEBOOK_APP_SECRET`
