# Implementation Checklist

## Before Coding
- [ ] Screenshot located and confirmed
- [ ] Target route/page identified
- [ ] Existing components/files identified
- [ ] Real data sources identified
- [ ] Mapping document completed

## During Coding
- [ ] Reused existing components where possible
- [ ] Preserved real API/data behavior
- [ ] Kept copy aligned to screenshot
- [ ] Avoided unrelated file edits
- [ ] Avoided backend/schema/auth changes unless requested

## QA
- [ ] Run type/check command
- [ ] Capture screenshot (if tooling exists)
- [ ] Compare to reference screenshot
- [ ] Patch key mismatches

## Final Report
- [ ] Screenshot used
- [ ] Page/route targeted
- [ ] Files changed
- [ ] Commands run
- [ ] Check/test outcome
- [ ] Captured screenshot path
- [ ] Remaining differences
- [ ] Known limitations
