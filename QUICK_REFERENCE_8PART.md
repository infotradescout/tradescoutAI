## 🔄 Data Flow Examples

### Example 1: User Asks About Roofing in Houston
```
"Find roofers in Houston"
↓
POST /api/assistant
  countyCode: "HARRIS"
  stateCode: "TX"
↓
resolveKnowledge()
  Layer 1: checkManualOverrides("roofer") 
    → No direct override for "roofer"
    → But check county_overrides/TX_HARRIS.json
    → Found! Returns county data (WACO requirement)
  
  Would return Layer 1 response
↓
Knowledge injected into prompt with:
  - Override: "WACO certification required"
  - County data: Climate, costs, codes
  - Local guide: roofing_houston.md
↓
Gemini generates response with context
↓
Response: Layer 1, High Confidence
```

### Example 2: User Asks About Marketplace
```
"Show me items under $50"
↓
POST /api/assistant
↓
resolveKnowledge()
  Layer 1: No override for "marketplace"
  Layer 2: readAutoCache("marketplace")
    → Returns 10 items from marketplace.json
    → Populated 5 minutes ago by crawler
  
  Returns with cache data
↓
Knowledge injected with marketplace list
↓
Gemini filters and presents options
↓
Response: Layer 2, High Confidence
```

### Example 3: Unknown Question (No Cache)
```
"What's the weather in Tokyo?"
↓
resolveKnowledge()
  Layer 1: No override
  Layer 2: No cache data
  Layer 3: DB query finds nothing
  Layer 4: searchInternet() called
    → Gemini searches web
    → Returns weather info
  
  Returns Layer 4 response
↓
Response: Layer 4, Medium Confidence
"Note: This information comes from web search, not our local cache"
```

## 🔧 Configuration & Customization

### Change Crawl Frequency
**File:** `server/index.ts`
```typescript
// Every 5 minutes (default)
cron.schedule("*/5 * * * *", ...)

// Change to every 10 minutes
cron.schedule("*/10 * * * *", ...)

// Change to every hour
cron.schedule("0 * * * *", ...)
```

### Add New County Override
**File:** `server/cache/manual/county_overrides/[CODE].json`
```json
{
  "[STATE]_[COUNTY]": {
    "name": "Full County Name",
    "climate": "Climate description",
    "buildingCodes": "Relevant codes",
    "commonTrades": ["Trade1", "Trade2"],
    "tips": "Local tips",
    "averageCosts": {
      "service": "$X - $Y"
    }
  }
}
```

### Add New Local Guide
**File:** `server/cache/manual/local_guides/[topic]_[county].md`
```markdown
# [Topic] in [County]

Description and tips...

## Key Considerations
- Point 1
- Point 2

## Typical Costs
- Item: $X - $Y
```

### Add Response Override
**File:** `server/cache/manual/overrides.json`
```json
{
  "responseOverrides": {
    "specific phrase": "Your override response here"
  },
  "forcedFacts": {
    "keyword": "Fact that always appears when keyword mentioned"
  }
}
```

## 🐛 Common Issues & Fixes

| Issue | Cause | Fix |
|-------|-------|-----|
| Cache not updating | Crawler not running | Check cron scheduler in logs |
| Slow responses | Using Layer 4 (internet) | Check if Layer 1-3 have data |
| Wrong county data | County code mismatch | Verify countyCode format |
| Hallucinations | Cache missing data | Populate with extractors |
| 404 on routes | Server not started | `npm run dev` |

## 🎓 Architecture Layers

### Layer 1: Manual Overrides (Highest Priority)
- Admin-controlled forced facts
- Response mappings
- County-specific data
- **Confidence:** HIGH

### Layer 2: Auto-Generated Cache (Primary Source)
- Refreshed every 5 minutes
- Crawler output
- Marketplace, contractors, groups, HOA
- **Confidence:** HIGH

### Layer 3: Live Database Queries (Fallback)
- Real-time data if cache insufficient
- Drizzle ORM queries
- Only if Layer 1-2 empty
- **Confidence:** HIGH

### Layer 4: Internet Search (Last Resort)
- Gemini web search
- Only if all layers insufficient
- **Confidence:** MEDIUM

## 🔐 Security Notes

### Sensitive Data Handling
- Extractors automatically strip passwords, emails, private fields
- Cache files contain only public-safe data
- Manual overrides managed by admins only
- No user data cached

### Admin Access
- Override system requires admin authentication (add to routes if needed)
- Manual files in `cache/manual/` controlled by admins
- Automatic cache cannot be manually edited
- All changes logged in crawler output
