# Community UI Redesign Plan

This document outlines the proposed changes for the Community UI redesign in the `tradescoutAI` repository.

## Goals
- **Modernize Aesthetics**: Update the visual style to be more clean, professional, and engaging.
- **Improve Layout**: Enhance the use of space, especially on mobile and desktop.
- **Enhance User Experience**: Improve interactions, clearer CTAs, and better discovery.

## Proposed Changes

### 1. Community Shell (`CommunityShell.tsx`)
- **Header**: Update the header with a more modern design, better typography, and clearer navigation.
- **Navigation**: Improve the desktop and mobile navigation menus.
- **Snapshot Banner**: Enhance the visual style of the rotating highlight items.

### 2. Community Feed (`community.tsx`)
- **Feed Layout**: Use a more "social media" like feed with better spacing and typography.
- **Tabs**: Update the tab design for better clarity and interaction.
- **Empty State**: Redesign the empty state to be more encouraging and visually appealing.

### 3. Community Composer (`CommunityComposerInline.tsx`)
- **Visual Style**: Modernize the composer with a cleaner look and better focus.
- **Interactions**: Improve the post-type selection and media upload experience.
- **CTAs**: Make the "Post" button more prominent and clear.

### 4. Community Post Card (`CommunityPostCard.tsx`)
- **Author Info**: Improve the visual hierarchy of the author's name, avatar, and role.
- **Category Badges**: Use more distinct and visually appealing badges for different post types.
- **Interactions**: Enhance the like, comment, and share buttons with better feedback.
- **Image Gallery**: Clean up the image gallery for better presentation.

### 5. Community Snapshot Rail (`CommunitySnapshotRail.tsx`)
- **Card Design**: Update the snapshot cards with a more modern and engaging design.
- **Discovery**: Improve the "View all deals" and discovery experience.

## Implementation Steps
1.  **Phase 1**: Update the `CommunityShell` and `CommunityTopNav`.
2.  **Phase 2**: Redesign the `CommunityComposerInline`.
3.  **Phase 3**: Enhance the `CommunityPostCard`.
4.  **Phase 4**: Update the main `Community` feed page.
5.  **Phase 5**: Final polish and testing.
