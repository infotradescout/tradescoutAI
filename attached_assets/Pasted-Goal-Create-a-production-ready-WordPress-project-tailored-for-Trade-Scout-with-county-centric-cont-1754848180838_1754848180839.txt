Functional Specs (Implement Exactly)
1) County & Trades (No fake data)
county taxonomy stores: FIPS (term_meta fips), state code, county name, slug.

Importer endpoint (admin): Upload CSV with columns:

state_code, state_name, county_name, fips (5-digit), optional population

Create/merge terms by fips. Log every change.

Cron (2am server): re-import the most recent county CSV in /private_data/counties/ if file hash changed.

2) Contractor Data Model
CPT contractor fields (register via PHP, no ACF dependency):

company_name (post_title), trades (taxonomy trade, multi), service areas (associate state/county terms), phone (E.164), email, website, years_in_business, license_number, insurance_doc URL (media), about, photos (gallery), min_job_size, availability_window, pricing_notes, response_time_sla, last_verified (date), verified flags (licensed, insured).

Public card shows: logo, name, trades, counties served (top 3 + “+X more”), click-to-call, email link, recommendation count, avg rating, years, badges, response time, last verified.

Detail page adds gallery, about, documents (if public), service tags.

3) Recommendations
CPT recommendation linked to contractor via post_meta; created by logged-in homeowner.

Rating model: 1–5 stars + short text (max 500 chars) + optional photo.

Aggregate rating (count, mean) computed and cached on contractor save; expose via REST for theme.

4) Boards & Sorting
/contractors/board and county pages render server-side list with filters:

Filters: trade (multi), state, county; mobile-first sticky CTA.

Sort options: default = Most Recommended, then Avg Rating, Years in Business, Last Verified. Tie-break: response_time_sla asc, then post_date desc.

Pagination SSR, with progressive JS enhancement (fetch via REST) if JS available.

5) Quote Calculators (CSV-driven, no sample data)
Admin → Trade Scout → Calculators: define services (e.g., Painting, Roofing, Flooring).

For each service, CSV importer required in /private_data/pricing/{service}.csv with columns (example schema — create code to read, do not include data):

fips,service_code,input_1_name,input_1_unit,input_2_name,...,base_low,base_high,adj_factor_*…

Calculator form builder maps inputs → formula:

Compute low/mid/high using (base_low/base_high ± adj_factors) based on inputs and county FIPS.

Output: range + “this is an estimate; contractors will confirm.”

Option to attach calculator output to any lead submission.

6) Lead Forms & Routing
Single server-side form engine (no JS required) with routes:

Call contractor now (reveals tel:; logs event).

“Have this contractor call me” (sends to selected contractor).

“Match me with top 3” (auto-selects three by performance-weighted round-robin within the county+trade, respecting daily caps and exclusion lists).

Routing rules (configurable in admin):

Weight = 50% quality (rating & verification freshness) + 30% recent acceptance rate + 20% speed to first response.

Caps per contractor/day and per week; overflow to next in weight order.

Notifications:

Email (contractor + admin) via wp_mail; optional SMS via webhook (admin setting to paste real URL & secret).

Homeowner confirmation email with board link and 3 contractors (for “top 3” flow).

Webhooks/CRM:

Admin UI to define POST endpoints + payload templates (must include fields for PII, calculator outputs, UTM).

7) Authentication & Roles
Integrate Nextend Social Login (Facebook) if installed; otherwise show settings to paste custom FB App ID/Secret (use WordPress OAuth hooks).

Guests: can browse; form submits & downloads require login (email or Facebook).

contractor_user can edit only their contractor post; changes go to moderation queue if “verified” flag is set.

8) Verification Workflow
/contractors/apply: multi-step (company info → docs upload → review).

Required uploads: COI (PDF), license doc; optional ID.

Admin review screen: approve, reject (with reasons), request changes; all actions logged.

Re-verification scheduler: every 6 months; email + dashboard banner until completed; auto-hide badges if overdue.

9) Accelerator Program (Stripe)
/contractors/accelerator: sales page. Create Stripe settings page for:

Products/prices (monthly, annual), optional add-ons (per-lead credits).

Webhook endpoint for subscription status (activate/deactivate role accelerator_member).

Accelerator dashboard: lead inbox (view/accept/decline), billing portal link, performance stats (CPL, acceptance rate).

Feature flags remain OFF until real Stripe keys + product IDs provided.

10) Free Growth Pack (Contractors)
/growth-pack gated form:

Required: email, company, trade(s), states/counties, size.

Delivery: email unique link + immediate download if consented.

Post-submit CTA: Apply to Board or View Accelerator.

11) SEO & Performance
Server-rendered HTML, critical CSS inline; defer non-critical.

Auto sitemap.xml, canonical, robots.

Schema generators:

ItemList for boards, LocalBusiness for contractor, Product/Offer for Accelerator, FAQPage for Growth Pack.

Image pipeline: compress to WebP on upload (PHP); srcset sizes.

Targets baked into theme: LCP ≤ 2.5s (mobile), CLS ≤ 0.1, A11y ≥ 95.

12) Security & Compliance
Nonces on all forms; hCaptcha/Turnstile integration toggles.

Rate limiting by IP & user; basic ASN blocklist support.

PII retention & export/delete tools (GDPR/CCPA) in admin; configurable retention window.

13) Analytics & Events
Settings for GA4 ID and Meta pixel IDs; print server-side events + minimal JS enhancement.

Standard events: view_contractor, click_call, submit_lead, quote_request, calculator_view, calculator_submit, share_board, login_success, apply_start/complete, verify_pass, accelerator_view/purchase, lead_received/accepted.
