## Crawler Scheduler Loop

```
SERVER STARTUP
    │
    ├─ import crawlerScheduler
    └─ startCrawlerScheduler()
        │
        ├─ Get CRAWLER_SCHEDULE from env
        │  (default: "*/5 * * * *")
        │
        └─ Start cron job
            │
            ├─ Every 5 minutes:
            │  │
            │  ├─ runCrawler()
            │  │  ├─ extractMarketplace()
            │  │  ├─ extractContractors()
            │  │  ├─ extractHOA()
            │  │  ├─ extractGroups()
            │  │  ├─ extractCounties()
            │  │  ├─ extractPublicProfiles()
            │  │  └─ extractFAQ()
            │  │
            │  └─ Write to cache/autogenerated/
            │     ├─ marketplace.json
            │     ├─ contractors.json
            │     ├─ hoa.json
            │     ├─ groups.json
            │     ├─ counties.json
            │     ├─ profiles_public.json
            │     ├─ faq.json
            │     └─ _metadata.json
            │
            ├─ OR manual trigger:
            │  POST /api/assistant/crawl-now
            │  → runCrawler() immediately
            │
            └─ Cache ready for AI queries
```

## Security Layers

```
USER INPUT
    │
    ├─ Validated (non-empty string)
    │
API REQUEST
    │
    ├─ CORS checked
    ├─ Rate limits (optional)
    │
CACHE CONTEXT
    │
    ├─ Only public data cached
    ├─ Passwords never cached
    ├─ API keys never cached
    ├─ Sensitive fields stripped
    │
AI PROMPT
    │
    ├─ Cache data only
    ├─ No external search enabled
    ├─ Instructions: "Use cached data only"
    │
GEMINI API
    │
    ├─ Call made with context
    ├─ Response parsed safely
    │
RESPONSE
    │
    └─ Sent to frontend
       Cache source tracked
       Stats included
```
