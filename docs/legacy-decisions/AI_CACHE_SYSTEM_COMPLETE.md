## How It Works

### Data Flow

```
User Query
    ↓
Cache Context Built
├─ Checks manual overrides
├─ Loads auto-cache
└─ Prepares for AI
    ↓
AI Prompt Enhanced
├─ "Here's your local data:"
├─ "[contractors] 150 cached"
├─ "[marketplace] 450 items"
└─ "Respond using this only"
    ↓
Gemini Responds
├─ Uses cache data
├─ No hallucinations
└─ Cites sources
    ↓
Response with Stats
├─ message: "Found 3 contractors..."
├─ cacheContext.used: true
└─ cacheContext.stats: {...}
```

### Crawler Operation

```
Every 5 minutes (or manual trigger)
    ↓
runCrawler() starts
    ├─ extractMarketplace()
    ├─ extractContractors()
    ├─ extractHOA()
    ├─ extractGroups()
    ├─ extractCounties()
    ├─ extractPublicProfiles()
    └─ extractFAQ()
    ↓
Data stripped of sensitive info
    ↓
Saved to cache/autogenerated/
    ├─ marketplace.json
    ├─ contractors.json
    ├─ ... etc
    └─ _metadata.json (timestamp)
    ↓
Knowledge Service reads cache
    ↓
AI uses in responses
```

## Quick Start

### 1. Install Dependencies
```bash
npm install
```
(Already done - `node-cron` should now be in node_modules)

### 2. Start Server
```bash
npm run dev
```

**What happens:**
- Server starts on port 5000
- Crawler scheduler initializes
- First auto-crawl runs immediately
- Caches populate with JSON files

### 3. Check Cache Status
```bash
curl http://localhost:5000/api/assistant/health
```

**Response shows:**
- Gemini configured: ✅
- Cache available: contractors (150), marketplace (450), etc.
- Scheduler status: active

### 4. Open Frontend
- Visit `http://localhost:5000`
- Click chat button (bottom right)
- Ask: "Find me contractors"

**AI responds using cached data!**

### 5. Monitor Crawling
```bash
# Check cache files
ls -la server/cache/autogenerated/

# Should see:
# contractors.json (updated recently)
# marketplace.json (updated recently)
# groups.json (updated recently)
# etc.
```

## Architecture Benefits

```
BEFORE (Without Cache)
├─ User asks question
├─ AI thinks (expensive, slow)
├─ Might hallucinate
├─ Calls Gemini API ($$$)
└─ 2-5 seconds per query

AFTER (With Cache)
├─ User asks question
├─ Read cache (instant)
├─ Inject local data
├─ Minimal AI thinking ($)
└─ 500ms per query
```
