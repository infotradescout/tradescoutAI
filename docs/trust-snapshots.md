# Trust Snapshots

Trust snapshots are precomputed per-user, per-county records used for contact gating
and read-only UI display. They are generated by a scheduled job and **never** computed
in the UI.

## Scheduler

The job runs via `server/services/trustSnapshotsJob.ts` and is scheduled in
`server/services/crawlerScheduler.ts`.

Env controls:
- `DISABLE_TRUST_SNAPSHOTS=true` disables the job
- `TRUST_SNAPSHOTS_SCHEDULE` overrides the cron schedule (default `0 2 * * *`)

## Backfill

```bash
node scripts/backfill-trust-snapshots.mjs
```

Dry run:
```bash
node scripts/backfill-trust-snapshots.mjs --dry-run
```

Force insert (ignore 24h window):
```bash
node scripts/backfill-trust-snapshots.mjs --force
```

## Baseline Scoring (current)

- If `address_verified` is false → CVS = 0
- If contractor and license/insurance not approved → CVS = 0
- Otherwise:
  - Base 50
  - +20 if `verification_status = approved`
  - +15 if license approved
  - +15 if insurance approved
  - Capped at 100

This is intentionally conservative and should be refined as full CVS logic is wired.
