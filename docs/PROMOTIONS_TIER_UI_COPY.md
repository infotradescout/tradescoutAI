# Promotions Tier UI Copy

## Section Headers

**Free Local Deals**
Browse verified discounts from local businesses in your area. No sponsorship, just valid deals.

**Promoted Campaigns**
Curated offers from regional and national partners. These are paid placements.

## Admin UI Labels

- **Tier**: Free Directory / Paid Campaign
- **Free Directory**: Listings appear only in the browse directory. No feed, snapshot, scout, or marketplace placements.
- **Paid Campaign**: Eligible for community feed, snapshot, scout, and marketplace placements based on targeting rules.

## User-Facing Indicators

- Free deals: No badge (just the deal itself)
- Paid campaigns: "Promoted" badge (neutral, factual)

## Error Messages

- "Free directory deals cannot enable placements. Set tier to 'Paid Campaign' to enable community feed, snapshot, scout, or marketplace visibility."
- "This promotion is a free directory listing. Placements have been disabled automatically."

## Admin Tooltip

**Tier**:
- **Free Directory**: Valid discount required. No exposure beyond the deals directory.
- **Paid Campaign**: Exposure placements allowed. Subject to Trust/CVS + relevance rules.

---

**Psychological Intent**: Clarity without judgment. Free stays free. Paid is explicit. Trust is preserved because the user always knows what they're seeing and why.
