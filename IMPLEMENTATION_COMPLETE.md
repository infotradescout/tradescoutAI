## 🧠 Part 6: 4-Layer Knowledge Service ✅

### Location
`server/services/knowledgeService.ts`

### Core Function
```typescript
export async function resolveKnowledge(
  request: KnowledgeRequest,
  gemini: GoogleGenerativeAI
): Promise<KnowledgeResponse>
```

### 4-Layer Resolution Process

#### **Layer 1: Manual Admin Overrides** (Highest Priority)
```typescript
function checkManualOverrides(message: string, countyCode?: string)
```
- Checks response overrides for exact matches
- Checks forced facts for keyword triggers
- Checks county-specific overrides
- **Return:** Layer 1, high confidence if found

#### **Layer 2: Auto-Generated Cache** (Primary Source)
```typescript
function readAutoCache(category: string)
```
- Reads from `cache/autogenerated/*.json`
- Detects category from message keywords
- Returns sanitized marketplace/contractor/group data
- **Return:** Layer 2, high confidence if cache populated

#### **Layer 3: Live Database Queries**
```typescript
async function queryWebsite(message, userId, countyCode)
```
- Queries Drizzle ORM tables directly
- Filters by county if provided
- Maps database fields to safe JSON
- **Return:** Layer 3, high confidence if results found

#### **Layer 4: Internet Search** (Last Resort)
```typescript
async function searchInternet(gemini, message)
```
- Calls Gemini generative API for web search
- Only triggered if Layers 1-3 insufficient
- **Return:** Layer 4, medium confidence

### Resolution Hierarchy
```
User Query
    ↓
Layer 1: Admin Override? → YES: Return with confidence HIGH
    ↓ NO
Layer 2: Cache data? → YES: Return with confidence HIGH
    ↓ NO
Layer 3: Database query? → YES: Return with confidence HIGH
    ↓ NO
Layer 4: Internet search? → YES: Return with confidence MEDIUM
    ↓ NO
Return: "I don't have information about that"
        Confidence: LOW
```

### Response Format
```typescript
{
  answer: "Resolved knowledge text",
  sources: ["Admin Override", "Cache", etc.],
  layer: 1|2|3|4,
  confidence: "high" | "medium" | "low"
}
```
