## Auto-Crawler Pipeline

```
┌──────────────────────────────────────────────┐
│ Every 5 Minutes (or manual trigger)          │
└──────────────────────────────────────────────┘
           ↓
┌──────────────────────────────────────────────┐
│ crawler/crawl.ts runs                        │
│ 1. extractMarketplace() → query DB           │
│ 2. extractContractors() → query DB           │
│ 3. extractHOA() → query DB                   │
│ 4. extractGroups() → query DB                │
│ 5. extractCounties() → query DB              │
│ 6. extractPublicProfiles() → query DB        │
│ 7. extractFAQ() → static data                │
└──────────────────────────────────────────────┘
           ↓
┌──────────────────────────────────────────────┐
│ Data Sanitization                            │
│ - Remove passwords, API keys, emails         │
│ - Keep only public data                      │
│ - Strip sensitive fields                     │
└──────────────────────────────────────────────┘
           ↓
┌──────────────────────────────────────────────┐
│ Write to Cache                               │
│ server/cache/autogenerated/                  │
│ - marketplace.json                           │
│ - contractors.json                           │
│ - hoa.json                                   │
│ - groups.json                                │
│ - counties.json                              │
│ - profiles_public.json                       │
│ - faq.json                                   │
│ - _metadata.json (timestamp)                 │
└──────────────────────────────────────────────┘
           ↓
┌──────────────────────────────────────────────┐
│ Ready for AI to Use                          │
│ Knowledge service reads these files          │
│ AI injects into prompts                      │
│ Responses are instant & accurate             │
└──────────────────────────────────────────────┘
```

## Key Configuration

### .env File
```bash
# REQUIRED
GEMINI_API_KEY=your_actual_key

# OPTIONAL (with defaults shown)
CRAWLER_SCHEDULE="*/5 * * * *"    # Every 5 min (default)
CRAWLER_ENABLED=true              # Auto-crawl enabled (default)
```

### Custom Crawler Schedule
```bash
*/5 * * * *      = Every 5 minutes (default)
*/15 * * * *     = Every 15 minutes
*/30 * * * *     = Every 30 minutes
0 * * * *        = Every hour
0 */2 * * *      = Every 2 hours
0 0 * * *        = Daily at midnight
0 0 * * 0        = Weekly on Sunday
```

## What Gets Cached

| Data | Source | Purpose |
|------|--------|---------|
| **marketplace.json** | DB query | Find items to buy/sell |
| **contractors.json** | DB query | Find verified professionals |
| **hoa.json** | DB query | Find HOA entries |
| **groups.json** | DB query | Find community groups |
| **counties.json** | DB query | County information |
| **profiles_public.json** | DB query | Public user profiles |
| **faq.json** | Static | Help documentation |
| **_metadata.json** | Auto-generated | Last crawl timestamp |

**What's NOT cached:**
- ❌ Passwords
- ❌ Email addresses (private)
- ❌ API keys
- ❌ Personal messages
- ❌ Admin-only data
- ❌ Anything marked private


## Troubleshooting

### Cache not updating?
```bash
# Check if crawler is running
curl http://localhost:5000/api/assistant/health

# Manually trigger crawl
curl -X POST http://localhost:5000/api/assistant/crawl-now

# Check cache files exist
ls -la server/cache/autogenerated/
```

### AI not using cache?
```bash
# Verify cache files have data
cat server/cache/autogenerated/contractors.json | head

# Check if knowledge service is working
# Look for cache context in responses
```

### Database connection issues?
```bash
# Verify DB is accessible
npm run db:push

# Check DB credentials in .env
# Look for errors in server logs
```
