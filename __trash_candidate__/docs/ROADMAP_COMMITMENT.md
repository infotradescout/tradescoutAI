# TradeScout Roadmap Commitment

## 🔒 IMMUTABLE SPECIFICATION

**Date Locked**: August 23, 2025  
**Status**: PERMANENT - No changes without explicit user authorization

## Core Commitment

This document serves as a permanent lock on the TradeScout roadmap defined in `TRADESCOUT_FULL_SPECIFICATION.md`. All development decisions, feature implementations, and architectural choices must align with the locked specification.

## Development Principles

### NEVER DEVIATE FROM:
1. **Universal Signup**: Single portal, multi-role support
2. **County-Centric Design**: 3,000+ county hubs nationwide
3. **Charitable Mission**: 10% profit split (Mike Rowe Works Foundation + local communities)
4. **Affiliate System**: Every user is an affiliate with 10% commission standard
5. **Verification-First**: Reviews only from verified users
6. **No Profile Boosting**: Contractors cannot boost profiles, only deal promotions
7. **Community-First Advertising**: Contextual, never impacts rankings

### MANDATORY ROADMAP PHASES:
- **Phase 1**: Contractors, Helpers, daily deal feeds
- **Phase 2**: Realtors + Dealers with boosts  
- **Phase 3**: Groups + in-app social
- **Phase 4**: HOA suite (finances, vendors, voting)
- **Phase 5**: Nationwide rollout
- **Phase 6**: Foundation + Coffee scaling → impact flywheel

## Implementation Guidelines

### When Making Development Decisions:
1. **First**: Check alignment with locked specification
2. **Second**: Verify phase priority order
3. **Third**: Ensure core principles are maintained
4. **Always**: Preserve multi-role, county-centric, and charitable foundations

### Prohibited Actions:
- Removing or altering core roles
- Changing county-based territorial structure
- Modifying charitable donation percentages
- Implementing profile boosting for contractors
- Deviating from verification-first review system
- Altering affiliate commission structure

## Emergency Override

Only the primary user can authorize deviations from this roadmap. Any requests for changes must be explicitly approved before implementation.

**This commitment ensures TradeScout maintains its vision and mission integrity throughout development.**
