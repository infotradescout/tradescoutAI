## 📞 Troubleshooting

### Server Won't Start
```
Solution: Check for port 5000 conflicts or npm installation
npm install  # Reinstall dependencies
npm run dev  # Try again
```

### Crawler Not Running
```
Solution: Check logs for scheduler messages
Look for: "🔄 Starting crawler scheduler"
         "✅ Crawler complete"
```

### Cache Not Updating
```
Solution: Check file permissions and disk space
ls server/cache/autogenerated/
```

### API Not Responding
```
Solution: Ensure server is still running
curl http://localhost:5000/api/scout/health
```
