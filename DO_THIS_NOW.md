# Do This Now (No Jargon)

If you want to focus on frontend only:

1. Double-click split-now.bat
2. Double-click open-frontend-workspace.bat
3. In that folder, run:
   - npm install
   - npm run dev

If you want backend only:

1. Double-click split-now.bat
2. Double-click open-backend-workspace.bat
3. In that folder, run:
   - npm install
   - npm run dev

That is it.
