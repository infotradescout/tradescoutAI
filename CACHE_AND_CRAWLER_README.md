# TradeScout Scout - Local Caching & Auto-Crawling Engine

## Overview

This is a **layered knowledge system** that makes Scout hyperlocal, fast, and accurate. Instead of relying on external APIs and hallucinations, Scout reads from:

1. **Manual Cache** (admin-controlled overrides)
2. **Auto Cache** (crawler-generated snapshots)
3. **Live Database** (real-time queries)
4. **Internet** (rare fallback only)

## How It Works

### 1. Auto-Crawler (crawl.ts)

**What it does:**
- Pulls data from your database via direct function calls (not HTTP)
- Strips out sensitive information
- Converts to JSON snapshots
- Saves to `cache/autogenerated/`

**Example:**
```typescript
// Before: Private data
{
  id: "123",
  companyName: "John's Plumbing",
  password: "secret123",     // ❌ Not cached
  apiKey: "xyz789",          // ❌ Not cached
  verified: true
}

// After: Public cache
{
  id: "123",
  companyName: "John's Plumbing",
  verified: true
}
```

**Runs:**
- Every 5 minutes (via cron scheduler)
- Or manually via `POST /api/assistant/crawl-now`
- Or triggered by DB mutations (create/update/delete)

### 2. Knowledge Service (knowledgeService.ts)

**What it does:**
- Reads cache files in priority order
- Checks manual overrides first
- Falls back to auto cache
- Returns with source tracking

**Priority order:**
```
Manual Override → Auto Cache → Empty Result
```

**Example:**
```typescript
const contractors = getContractorsKnowledge();
// Result: {
//   source: "auto" or "manual",
//   data: [...],
//   itemCount: 150
// }
```

### 3. Scout (scout.ts)

**What it does:**
- Injects cache context into AI prompt
- AI responds using cached data
- Falls back to actions only if needed

**Cache context for each query:**
```
📚 LOCAL CACHE CONTEXT:
✓ 150 verified contractors available (cached)
✓ 450 marketplace listings available (cached)
✓ 12 FAQ entries available (cached)

RELATED CACHED DATA (3 results):
1. [contractors] John's Plumbing - Licensed & Insured
2. [marketplace] Vintage Sink - $45 (Perfect condition)
3. [faq] How do I find contractors?
```

### 4. Scheduler (crawlerScheduler.ts)

**Default schedule:** Every 5 minutes (`*/5 * * * *`)

**Customizable via env:**
```bash
CRAWLER_SCHEDULE="0 */2 * * *"   # Every 2 hours
CRAWLER_SCHEDULE="0 0 * * *"     # Daily at midnight
```

## Data Flow Example

**User:** "Find contractors in California"

```
1. Frontend sends message to /api/assistant
   ↓
2. Backend loads cache context:
   - Contractors: 150 cached
   - Counties: 3145 cached
   ↓
3. AI prompt includes cache data:
   "RELATED CACHED DATA: 
    - [contractors] John's Plumbing (San Francisco)
    - [contractors] Green Services (LA)"
   ↓
4. Gemini responds naturally using cache:
   "I found 2 verified contractors in California..."
   ↓
5. Response sent to frontend with cache stats
```

## Manual Cache Overrides

**Purpose:** Admin can manually set data that overrides auto-cache

**Example:** `cache/manual/contractors_overrides.json`
```json
[
  {
    "id": "featured-001",
    "companyName": "Featured Partner: Top Plumbing",
    "note": "Admin promoted this contractor"
  }
]
```

**Priority:**
1. If manual override exists → use it
2. Else if auto cache exists → use it
3. Else → return empty

## Troubleshooting

**Cache not updating?**
```bash
# Check cache stats
curl http://localhost:5000/api/scout/cache-stats

# Manually trigger crawl
curl -X POST http://localhost:5000/api/scout/crawl-now

# Check server logs for errors
```

**AI not using cache?**
```bash
# Verify cache files exist
ls -la server/cache/autogenerated/

# Check health endpoint
curl http://localhost:5000/api/scout/health

# Look for "cacheContext" in AI response
```

**Crawler failing?**
```bash
# Check database connection
npm run db:push

# Verify schema is correct
# Look for extractors errors in logs
```
