## Cross-build owners, impacts, invalidated evidence, and merge order

The marketplace build is the only active build and claims the new route, state, data projection, UI, metadata, existing-profile protection, and optional Direct Connect handoff owners. It depends on main revision `999481b602c2f99499c69a0c90b3840d4af0a158` and must rebase and rerun exact-head proof if `main` moves before publication.

Any change to App route ordering invalidates standalone and custom-domain protection. Any Direct Connect change invalidates the scalar compatibility and multi-selection safety evidence. Any UI or asset change invalidates relevant screenshots.

The separate customer-card draft pull request is not a dependency and must not be merged into this branch. The JW Stone marketplace draft is published independently and remains held for its own visual proof.

## Release reconciliation and closure

Before as-built reconciliation, every included requirement must advance to verified or remain explicitly partial with a named blocker. The evidence file records exact revision, environment, configuration, expected and actual results, browser captures, and non-flaky state.

Release closure is deliberately outside this build. A later authorized release must confirm the draft commit still matches its evidence, merge only after visual approval, observe Render health and exact deployed commit, smoke `/jw-stone`, recheck `/u/jw-stone` and the custom domain, and retain a fast application revert path.
