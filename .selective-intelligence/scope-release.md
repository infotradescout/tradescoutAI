# Scope and Release — 1.4.0 Spatial Studio

## Smallest complete loop

A visitor opens the existing JW Stone countertop planner, selects an actual JW catalog item, explores that texture in a navigable kitchen, bathroom, or living-room scene, adjusts crop, vein direction, and scale, optionally adds measured fabrication details, saves locally or creates a safe design-only share, and deliberately hands the selection to the existing TradeScout request flow with availability marked for JW confirmation.

## Included and mandatory

Included: three real 3D scene families, catalog texture mapping, camera controls, measured geometry, optional openings/seams/waterfalls/edges/applications, truthful inventory details, local save, safe share, and existing gated request handoff. Mandatory: default no openings; no second inventory authority; no public price; mobile and keyboard operation; reduced-motion behavior; texture/loading/WebGL recovery; serialization and exact-revision browser proof.

## Later or out

Later: canonical live availability, reservations, job scheduling, slab allocation, optimization, quoting, pricing, payments, customer accounts, server-side design persistence, automated routing, and photorealistic manufacturing-grade cut sheets. Out and still void: customer-path guides, Learn about stone, recommendation theater, yellow eyebrows, Call-for-availability marketing, and changes to the separate marketplace or existing JW profile.

No build, release, live, push, merge, or deployment claim follows from this definition lock. Those require their own verified transitions and owner authority.
