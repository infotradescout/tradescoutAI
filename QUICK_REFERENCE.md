# 🚀 Quick Reference - Scout System

## One-Line Summary
**Hyperlocal Scout using cached database snapshots, auto-updated every 5 minutes, zero hallucinations.**

---

## Start Here (3 Steps)

```bash
# 1. Install & Configure
npm install
echo 'GEMINI_API_KEY=your_key' >> .env

# 2. Run
npm run dev

# 3. Test
curl http://localhost:5000/api/assistant/health
```

That's it. Everything else is automatic.

---

## Key Files You Need to Know

| File | Purpose |
|------|---------|
| `server/crawler/crawl.ts` | Data extraction (runs every 5min) |
| `server/services/knowledgeService.ts` | Cache reading logic |
| `server/routes/scout.ts` | AI chat endpoint (aliases /api/assistant) |
| `server/cache/autogenerated/` | **Cache lives here** |
| `client/src/components/ScoutChat.tsx` | Chat widget |

## API Cheat Sheet

```bash
# Chat (main endpoint)
curl -X POST http://localhost:5000/api/scout \
  -H "Content-Type: application/json" \
  -d '{"message":"Find contractors"}'

# Health check
curl http://localhost:5000/api/scout/health

# Cache stats
curl http://localhost:5000/api/scout/cache-stats

# Manual crawl (admin)
curl -X POST http://localhost:5000/api/scout/crawl-now
```

## How It Works (Simple)

```
1. User asks AI a question
   ↓
2. System loads relevant cached data
   ↓
3. Injects cache into AI prompt
   ↓
4. AI responds using ONLY cached data
   ↓
5. No hallucinations, instant response
```

## Configuration (.env)

```bash
# Required
GEMINI_API_KEY=sk-proj-your_key

# Optional (with defaults)
CRAWLER_SCHEDULE="*/5 * * * *"    # Default: every 5 min
CRAWLER_ENABLED=true              # Default: enabled
```

### Custom Schedules
```bash
*/5 * * * *      Every 5 minutes (default)
0 * * * *        Every hour
0 0 * * *        Daily midnight
0 */4 * * *      Every 4 hours
```

## What Happens on Startup

```
npm run dev
    ↓
Server boots
    ↓
Load crawlerScheduler
    ↓
Initialize cron job (every 5 min)
    ↓
Run first crawl immediately
    ↓
Populate cache with fresh data
    ↓
Wait for users
    ↓
Every 5 minutes: auto-update cache
```
